# PWA Quick Start - SACCO Management System

## 🚀 Install the SACCO App in 3 Steps

### For Desktop Users (Windows, Mac, Linux)

1. **Visit the SACCO website** and log in
2. **Look for the install banner** in the bottom-right corner
3. **Click "Install"** and you're done!

The app icon will appear on your desktop. Click it anytime for instant access!

### For Mobile Users (Android, iPhone)

**Android:**
1. Open the SACCO website in Chrome
2. Tap "Install SACCO App" banner
3. Tap "Install" → App added to home screen

**iPhone/iPad:**
1. Open the SACCO website in Safari
2. Tap Share button (□↑) → "Add to Home Screen"
3. Tap "Add" → App added to home screen

## 🎯 Quick Shortcuts

After installing, right-click (desktop) or long-press (mobile) the app icon for quick access to:
- Dashboard
- Members
- Backups

## 📱 Using the App

Once installed:
- **Desktop**: Double-click the SACCO icon on your desktop
- **Mobile**: Tap the SACCO icon on your home screen
- **Works exactly like the website** - same features, same login

## ❓ Need Help?

**Can't see the install button?**
- Make sure you're using Chrome, Edge, or Safari
- Check that the site is using HTTPS (secure)
- Try refreshing the page

**Want to uninstall?**
- Desktop: Right-click icon → Uninstall
- Mobile: Long-press icon → Remove/Uninstall

## 🔧 For Administrators

Before users can install, you need to:

1. **Generate App Icons**
   - Visit: `http://your-site/images/icons/generate-icons.html`
   - Click "Download All Icons"
   - Save all 8 icons to `public/images/icons/`

2. **Verify Setup**
   - Check that `manifest.json` exists in `public/`
   - Check that `sw.js` exists in `public/`
   - Ensure site is served over HTTPS

3. **Test Installation**
   - Visit your site
   - Install banner should appear within a few seconds
   - Click install to test

That's it! Your users can now install the SACCO app with one click.
